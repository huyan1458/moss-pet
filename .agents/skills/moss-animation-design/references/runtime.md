# 文件恢复与客户端边界

## 分享链接

分享链接中的 `sharepet_` 标识用于领养，不是作者或接收者的宠物 ID。当前 Pets 的领养操作会在接收者的宠物库创建自己的副本；后续操作使用返回的 ID。领养和启用是两步，成功领养不等于当前宠物已切换。

个人分享链接公开；企业分享链接遵循相同工作区共享会话的访问规则。分享快照只包含名称、简介和精灵图，不暴露所有者身份。创建分享需要用户明确要求并确认相应受众；不为一般定制任务自动发布。新版本发布时核对链接快照，失效或不兼容时使用 PNG 路径。

## 文件与导入

当前成品为v2透明PNG：1536×2288，8列×11行，每格192×208；73个使用格、15个透明空格。行帧数为`6,8,8,4,5,8,6,6,6,8,8`。这是一张精灵图，不是普通PNG查看器中直接播放的动画。

使用仓库的原文件即可恢复相同素材；名称和简介是导入时的独立元数据。PNG不携带账号宠物ID、全局偏好或客户端逻辑。

本项目通过当时可用的Pets工具验证并导入v2。接收者需要有兼容的自定义宠物功能；可用工具时验证原文件后创建或更新目标宠物，不重生成。没有工具或入口时如实交付文件，不写入猜测的应用私有目录。

[公开Pets文档](https://learn.chatgpt.com/docs/pets)目前对网页上传仍列出1536×1872的v1格式；桌面和网页入口也不同。不能把本项目实测推广为所有版本均可直接上传v2。遇到只支持v1的目标，应说明会缺少方向槽，先确定是否接受降级，不静默裁行或改尺寸。

## 本项目观察到的播放行为

下表来自2026-10-12对OpenAI.Codex 26.1007.2314.0的本地代码检查，属于版本限定证据，不是公开API承诺。

| 项目 | 行为与影响 |
| --- | --- |
| idle | 六帧一轮6600ms |
| 悬停 | 使用jumping即row 4；每轮840ms，非循环模式三轮后idle |
| 左右拖动 | 分别row 1/2；每轮1060ms，三轮约3180ms后可能回idle；换向重播 |
| look | row 9/10按22.5°量化，直接显示静态格，不运行该格中的扫描计时 |
| 状态覆盖 | idle/running/waving才传入look；hover jumping可能屏蔽输入注视 |

`config/animation.json` 的 `durations_ms` 用于预览匹配已观察时序，修改它不会修改客户端动画速度。方向格里的演示时长也不是客户端补间。

## 触发异常的最短排查

先确认宠物已启用、目标格包含预期动作，再看当前应用是否支持该触发。输入框有文字不等于编辑器仍有有效光标目标：本项目曾在移开宠物、重新点击文字末尾后恢复低头扫描。该操作有效，但原始失效究竟是悬停覆盖、焦点还是目标更新未被隔离。

减少动态效果、应用版本和有效状态都可能改变显示。确认这些条件后才改素材；不要用“重新上传一次”代替诊断，也不承诺同一PNG在不同宿主有完全相同的触发效果。
